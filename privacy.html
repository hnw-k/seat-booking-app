Privacy Policy

Last updated: May 2026

1. What data do we collect?

The Seat Booking Application doesn't collect or deliver any personal data to the server. All information provided by user (seat selections, service/movie preferences, and cookie acceptance) is stored in the browser’s localStorage.

2. How do we use localStorage?

We use the localStorage API of browser (which functions similarly to cookies) to:

  • Remember which seats user has booked or reserved.
  • Remember the movie services user created (names, prices).
  • Remember user's cookie preference (so we don’t show the banner repeatedly).

No data is sent to any external server. All data are saved on user's device.

3. user's rights

Since no personal data leaves user's device, user has full control. user can clear all stored data at any time via user's browser settings (clear "local storage" for this website). This will reset user's seat bookings and cookie preferences.

4. Third-party services

This appliction does not use Google Analytics, Facebook Pixel, or any other tracking service.

5. Changes to this policy

Any future changes will be reflected on this page. users are advised to review this Privacy Policy periodically.
